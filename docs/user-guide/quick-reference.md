# 🎮 ZyraX Quick Reference - New Features

## 💰 Economy

| Command | Usage | Cooldown |
|---------|-------|----------|
| `/work` | Earn 50-200 coins | 1 hour |
| `/slots <bet>` | Slot machine (min 10, max 10k) | None |
| `/gamble <amount>` | 50/50 bet (max 50k) | None |
| `/richest` | Top 10 by coins | None |

**Tips:**
- Work gives level bonus: `(level × 5) coins`
- Slots payouts: 🍒2x 🍋3x 🍊4x 🍇5x 7️⃣10x 💎20x

---

## 👤 Profile

| Command | Usage | Cooldown |
|---------|-------|----------|
| `/profile [@user]` | View profile card | None |
| `/setbio <text>` | Set bio (max 200 chars) | None |
| `/rep <user>` | Give +1 reputation | 24h per user |

**Profile Shows:**
- Level, XP, coins, reputation
- Messages sent, marriage status
- XP rank, wealth rank

## 💡 Pro Tips

1. **Work** every hour for steady income + level bonus
2. **Trivia** is skill-based earning (50-200 coins)
3. **Rep** people you appreciate (24h cooldown each)
4. **Ship** results are consistent (same pair = same %)
5. **Slots** high risk/high reward (up to 20x!)
6. **Profile** shows your ranks and stats
7. **Leaderboards** for competition

---

## 🏆 Earning Strategy

### Conservative (Safe):
1. `/daily` every 24h → 100-300 coins
2. `/work` every 1h → 50-200 + level bonus
3. `/trivia` when bored → 50-200 coins

**Expected:** 500-1000 coins/day

### Moderate (Balanced):
1. Daily + Work (above)
2. `/slots 100` occasionally → 2x-20x
3. Save up, gamble bigger

**Expected:** 1000-3000 coins/day

### Aggressive (Risky):
1. Work to build balance
2. `/gamble <big amount>` → 2x or lose
3. `/slots <max bet>` for jackpots

**Expected:** Big wins or big losses!
